# 🐍 Among Snakes

**Among Snakes** es un videojuego de estrategia y supervivencia basado en el clásico juego de la serpiente, desarrollado en Python. El jugador se enfrenta a una serie de retos en un entorno dinámico que incluye obstáculos, enemigos controlados por inteligencia artificial, y distintos objetivos a alcanzar.

---

## 🎮 Características del juego

- ✅ Juego en 2D basado en el clásico "Snake"
- 🤖 Implementación de IA para enemigos
- 🧠 Múltiples tipos de jugadores y comportamientos
- 🎯 Sistema de puntuaciones y objetivos dinámicos
- 🧱 Obstáculos y mapa personalizado
- 🖥️ Interfaz gráfica con `Tkinter` o similar (snakegui.py)

---

## 📁 Estructura del proyecto

```
Among_Snakes/
├── Code/
│   ├── main.py            # Archivo principal para lanzar el juego
│   ├── snake.py           # Lógica de la serpiente
│   ├── jugador.py         # Gestión de los jugadores
│   ├── ia.py              # Lógica de la inteligencia artificial
│   ├── mapa.py            # Estructura del mapa
│   ├── obstaculo.py       # Objetos bloqueadores en el juego
│   ├── objetivo.py        # Elementos a recolectar o evitar
│   ├── puntuaciones       # Archivo con puntuaciones
│   └── snakegui.py        # Interfaz gráfica del juego
├── Documentacion.pdf      # Documento técnico del proyecto
├── LICENSE
└── README.md
```

---

## 🚀 Requisitos

- Python 3.7 o superior
- Bibliotecas estándar de Python (posiblemente `tkinter` para GUI)

---

## ⚙️ Ejecución

1. Asegúrate de tener Python instalado.
2. Navega a la carpeta `Code/`:
   ```bash
   cd Code
   ```
3. Ejecuta el juego con:
   ```bash
   python main.py
   ```
